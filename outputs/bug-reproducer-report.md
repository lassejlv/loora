## Approved fix

Implemented a model-specific image capability gate at the client, server message boundary, and viewCanvas tool output. Mini now maps to vision-capable MiniMax-M3; GLM models remain blocked.

**Why this is causal:** This is a containment measure, not a claimed causal fix for the intermittent provider rejection. It guarantees that image data is sent only to models explicitly enabled in the capability allowlist.
