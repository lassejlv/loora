Loora

Design on a native canvas.

A GPUI-powered design workspace — infinite canvas, local save, and an MCP endpoint for agents that can edit with you.

Get Loora See the craft

Built for the canvas, not the browser tab.

Loora is a native desktop app — GPU-backed chrome, document engine, and routing that feels like the web without living in one.

  • Canvas Nodes, camera, and transforms

    Pan, zoom, and compose frames with a document engine that persists locally.

  • Agents MCP on loopback

    Point Claude, Codex, Cursor, or OpenCode at 127.0.0.1:6767/mcp and mutate the live canvas.

  • Chrome Dark by default

    Cursor-dark surfaces — #141414 floors, hairline borders, quiet accent blue for selection.

The stack underneath.

Rust workspace. GPUI from Zed. Components you can reuse.

loora-ui gpui-router loora-engine loora-mcp loora-desktop
